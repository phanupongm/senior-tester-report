S-001Students can read other students' results by changing the IDCritical
Location
src/routes/results.ts:42
Also at
src/routes/answers.ts:18
URL
/api/results/124
Persona
Intruder
OWASP / CWE
A01 · CWE-639
Steps to reproduce
  1. Log in as student1@test.local
  2. Request GET /api/results/124 (owned by student2)
  3. Response is 200 with student2's score and answers
Expected
403 Forbidden
Actual
200 OK with another student's data
Evidence
{"studentId": 2, "score": 87, "answers": [...]}
How to fix

Load the result scoped to the logged-in user, or check ownership before returning it. Apply the same check in answers.ts.

const result = await db.result.findFirst({
  where: { id: req.params.id, studentId: req.user.id },
});
if (!result) return res.sendStatus(404);
